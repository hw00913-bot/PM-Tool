# 原型设计规范 · 云呼叫桌面管理端
项目当前确认的设计要求优先，默认风格采用本规范。风格版本及已确认例外记录在项目 `docs/design-style.md`。场景工作核对派发附带的项目风格正文及摘要。导航名称、角色、业务字段和权限来自本轮冻结需求。

## 1. 风格与基础尺寸

界面采用**白色顶栏、深蓝灰侧栏、浅灰工作区、白色内容面板**。整体紧凑、便于连续操作。层级主要靠标题、留白和分隔线表达。蓝色集中用于选中态、链接和当前任务的主要动作。筛选卡和表格卡使用细边界或轻阴影。

| 项目 | 云呼叫默认规范 |
| --- | --- |
| 品牌与交互 | 主色 `#1677ff`，主操作悬停 `#0958d9`。内容区的选中项用浅蓝 `#e6f4ff` 和深蓝文字。左侧导航当前项用蓝底白字。 |
| 页面与面板 | 页面底 `#f0f2f5`，白色面板 `#ffffff`，浅灰表头 `#fafafa`，通用分隔线 `#e8e8e8`，控件边框 `#d9d9d9`，表格悬停底 `#f5f8ff`。 |
| 导航 | 白色顶栏高 **58px**，左右留 **20px**。宽屏侧栏宽 **244px**，背景 `#2f4050`，区域标题、展开分组和底部背景 `#263746`。一级项高约 **42px**，子项 **36px**。子项悬停底 `#344b5e`。 |
| 字体与层级 | 系统字体加中文字体回退，优先 `-apple-system`、`BlinkMacSystemFont`、`PingFang SC`、`Microsoft YaHei`、`Segoe UI`。正文 **14px**，表格、表单与按钮通常 **13px**，辅助信息 **12px**。通用页标题 **20px / 600**，行高 **30px**。页面正文 `#1f1f1f`，组件主文 `#262626`，次级 `#595959`，辅助 `#8c8c8c`。 |
| 留白与圆角 | 宽屏内容区内边距 **22px 24px 32px**。间距基础档 **4 / 8 / 12 / 16 / 24 / 32px**。状态标签、通用控件、内容面板的圆角分别为 **4 / 6 / 8px**。 |
| 控件 | 查询、输入、下拉与常规按钮对齐为 **34px** 高，紧凑按钮 **28px**。主按钮蓝底白字，次按钮白底描边，行操作用文字按钮。危险行操作 `#cf1322`，禁用行操作 `#bfbfbf`。字段保留可读标签。按钮和链接的键盘焦点使用 2px 蓝色轮廓和 3px 偏移。 |

状态标签使用文字加颜色，默认高约 **24px**、字 **12px**。共享组件的文字／背景配对为成功 `#389e0d / #f6ffed`、处理中 `#0958d9 / #e6f4ff`、警告 `#d46b08 / #fff7e6`、失败 `#cf1322 / #fff1f0`、中性 `#666666 / #f5f5f5`。空数据、待输入、权限受限和请求失败分别解释原因与下一步。禁用外观和实际阻断是两项检查。

## React 与 Ant Design 的对应规则

项目已确认风格和本 Skill 的云呼叫基线决定视觉要求。Ant Design 组件通过 `src/layouts/PrototypeLayout.jsx` 的唯一根 `ConfigProvider` 实现这些值。外壳 CSS 负责导航、页面分区和滚动；组件颜色、字号、尺寸与圆角优先用全局或组件 Token 配置。场景差异写成有范围的组件配置或项目例外。用项目的语义 Token 对应组件的默认、悬停、键盘焦点和禁用状态，基座和实际待验页面按同一映射核对。 [Primer 的设计 Token 与交互状态](../references/engineering-verification/SKILL.md#design-tokens-and-states)

| 规范 | 模板实现 |
| --- | --- |
| 正文14px、控件13px、紧凑按钮12px | 全局 `fontSize:14`，`Button.contentFontSize:13`、`Input.inputFontSize:13`、`Select.fontSize:13`、`Table.cellFontSize:13`。 |
| 常规34px、紧凑28px | `controlHeight:34`、`controlHeightSM:28`。 |
| 白卡片8px、确认弹窗10px | `Card.borderRadiusLG:8`、`Modal.borderRadiusLG:10`。 |
| 表头44px、单行表体52px | Table Token 配置颜色、13px字和横向14px内边距。头／体不同高度由 `prototype.css` 内限定在 `.prototype-main .ant-table-wrapper` 的共用规则表达。核对实际渲染的表头和表体高度。 |
| 520px确认层、右侧管理抽屉和68px头尾 | 场景按本节页面类型设置 Modal／Drawer 的宽度和 `styles`，复验窄窗与长内容。 |

根主题内使用 Ant Design `App` 提供提示与弹层上下文。场景需要命令式消息或确认时，从 `App.useApp()` 取得对应实例，或使用组件 Hooks 的上下文容器，使提示和表单共用当前主题。 [Ant Design 主题与上下文说明](https://ant.design/docs/react/customize-theme/)

## 2. 外壳与页面结构

```text
应用外壳
├── 顶栏 · 产品标识 → 一级业务域 → 当前品牌/租户/角色/账号等上下文
├── 主体
│   ├── 左侧 · 当前业务域标题 → 可折叠的功能分组 → 当前功能
│   └── 右侧 · 独立滚动的业务内容
└── 共用弹层与状态提示
```

- **导航只显示当前授权范围内的入口。** 一级域用蓝色文字与下划线标识选中，左侧选中对应功能并展开父组。可折叠组标明展开状态，当前项使用 `aria-current`。详情、编辑、审批和只读抽屉从所属功能进入。壳和内容各自负责自己的标题层级，去掉重复页签、面包屑和顶部空白。菜单用简短的业务名，工程编号和验证证据在项目资料中查看。
- **滚动留在对应区域。** 主内容纵向滚动，宽表在表格容器内横向滚动，抽屉正文独立滚动，标题和页脚操作保持可达。云呼叫在 **841–1180px** 将侧栏收为 **232px**，**≤840px** 为 **176px** 并保留文字和组内展开。复验窄窗的控件换行和操作可达性，支持范围由本项目确认。
- **React 组件与共享样式。** 使用 Umi 项目模板的路由和 Ant Design 组件。共用外壳、控件和页面沿用同一份设计变量。
- **静态模式的可选布局。** 已确认使用静态模式的项目可沿用现有目录布局，也可按公共外壳、场景内容及本地 Mock 分目录。公共外壳统一维护样式变量、导航、控件和弹层。从本轮确认的 `index.html` 使用包内相对资源，核对实际 `file://` 入口的渲染。

| 页面类型 | 结构和交互 |
| --- | --- |
| **标准管理列表** | 页面标题及必要说明 → 白底筛选区 → 工具栏 → 表格卡 → 分页。筛选标签置于控件上方，查询与重置对齐控件底边。查询和重置回到第一页，区分筛选草稿与已应用条件。新建、批量、导出只在对应任务有需要时显示。 |
| **表格与行操作** | 通用表头 **44px**、行 **52px**，单元格横向约 **14px**。宽表由自身容器横向滚动，必要时固定右侧操作列。行操作保持文字标签，普通为蓝色、危险为红色、禁用为灰色。页脚展示总数及翻页，分页按钮约 **30×30px**。长编号可截断显示，详情可复制完整值。 |
| **分组与明细列表** | 关联层级用左侧紧凑分组、右侧明细的结构。参考业务分类页的「左侧一级分类 → 右侧二级列表」。新建可带入已选分组，切换分组时右侧条件与结果同步更新。用于选择数据范围的左栏与全局导航各有职责。 |
| **编辑、详情与确认** | 常规编辑和只读详情走右侧抽屉，常用宽度 `min(760px, 82vw)`，头尾区约 **68px**。表单按业务分区，桌面两列，长文本和错误说明可占整行，窄窗可改单列。编辑底部右对齐「取消／保存」，只读详情提供关闭。短确认居中，约 **520px**、最大 **90vw**，圆角 **10px**，写清操作对象与影响。复杂导入或配置按实际需要使用宽层或步骤流程。 |
| **工作台** | 将当前待办或队列、当前对象摘要、主要处理区和回访／历史／辅助信息分区。操作围绕当前对象，辅助信息保留在相邻区域或局部展开。云呼叫坐席样例的三栏约为 **280px / 自适应 / 380px**，右侧可收起，窄窗可移到下方。该分栏用于队列式办理。缺失来源明确显示「暂未对接数据」。普通配置列表沿用列表结构。 |

普通表单离开前有未保存内容时，提供「取消／放弃修改／保存并继续」。错误就近绑定字段或操作，阻塞原因留在当前界面。弹层有可读标题、关闭入口及键盘焦点，关闭后回到触发处。短时反馈可用统一提示，关键保存结果用可见状态呈现。

## 3. 视觉检查

使用任务指定的实际候选和入口。React 使用候选的构建入口，静态模式使用候选的 `index.html`。以项目风格版本、已确认例外和公共样板为对照，在相同视口、同版样例数据下检查。

- 核对导航高亮和分组展开、标题层级、筛选区和表格顺序。检查列表、表单、弹层和抽屉在长内容与窄窗中的滚动、换行和操作可达性。
- 核对实际渲染的组件尺寸、文字层级、语义 Token 与状态外观。共用 Token 或组件的差异按实际使用范围定位受影响页面和状态。
- 核对空态、禁用、校验错误及权限受限的可见反馈。禁用控件外观可辨识属于视觉证据，点击或提交实际被拦截属于业务证据。两类观察分别记录。
